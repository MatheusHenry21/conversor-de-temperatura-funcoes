🚀 Funcionalidades:
Converter Celsius → Fahrenheit;
Converter Celsius → Kelvin;
Converter Fahrenheit → Celsius;
Converter Fahrenheit → Kelvin;
Converter Kelvin → Fahrenheit;
Converter Kelvin → Celsius.

🧠 Conceitos aplicados:
Criação e uso de funções em Python;
Estruturas condicionais (if, else);
Estrutura de repetição (while True);
Dicionário para mapeamento das opções;
Entrada e saída de dados no terminal.

💻 Como executar:
Tenha o Python 3 instalado no computador.
Baixe o arquivo conversor_temperatura.py.
No terminal, vá até a pasta onde o arquivo foi salvo e execute:

python conversor_temperatura.py


Escolha uma das opções do menu e digite a temperatura desejada.

🧩 Exemplo de uso
1 - Celsius para Fahrenheit
2 - Celsius para Kelvin
3 - Fahrenheit para Celsius
4 - Fahrenheit para Kelvin
5 - Kelvin para Fahrenheit
6 - Kelvin para Celsius
Digite a opção que você deseja utilizar: 1
Digite a temperatura: 25
Temperatura convertida: 77.00
